Where each math teacher is, by period, for the new math dashboard. Type a room in any cell; leave it empty if the teacher isn't teaching then. The Studium column is each teacher's Studium location, which the dashboard shows during Studium; AP is where they are during Activity Period.

This grid is the quick view. Each teacher's courses, room nicknames, and both semesters at once are on Math teachers; saving either page updates the other.

Prefecting? Put a * on the location, like *Cafeteria. Works in any column. The dashboard then shows that teacher as prefecting there instead of teaching.

Jr/Sr classes: switch on Jr/Sr next to a class. When that period lands on lunch, Jr/Sr classes meet in the later wave, so the dashboard shows the teacher at lunch first and teaching after. Classes left off follow the Fr/So times.
